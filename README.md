# TB GUITARES

Site vitrine premium pour la présentation et la vente sur demande de guitares électriques et acoustiques haut de gamme. Pas de panier ni de paiement en ligne.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS 4
- Déploiement prévu sur Vercel
- Supabase prévu pour le catalogue administrable, l'authentification et les photos

## État du projet

Cette première version est une base front-end avec données de démonstration. Le back-office, Supabase, l'authentification, le stockage des images et l'envoi serveur du formulaire de contact restent à développer. Le formulaire actuel ouvre le logiciel de messagerie via un lien mailto.

Les visuels Unsplash sont temporaires : remplace-les par les photos réelles des instruments avant mise en ligne.
